# PSX Dashboard

Lightweight Streamlit deployment for the PSX engine.

Daily candle research runs in this repository, using pinned read-only engine data. Research evidence has its own small branch, keeping databases, chart reports and daily commits out of main. See [the audit](docs/candle-research/AUDIT.md) and [cloud research](docs/candle-research/CLOUD_RESEARCH.md). Research does not change live calls or claim guaranteed profit.
